## Summary

This PR fixes several issues affecting code reliability and adds comprehensive test coverage for the core trading environment.

## Changes

### Bug Fixes
- Replace bare `except` clauses with specific exception types (7 instances across 3 files)
- Fix missing `linear_schedule` import in hyperparameter optimization module
- Update deprecated pandas `fillna` API for pandas 2.0+ compatibility
- Complete migration from deprecated `gym` to `gymnasium` (3 remaining files)

### Testing
- Add comprehensive test suite for `StockTradingEnv` (31 tests, 452 lines)
- Tests cover initialization, reset, step logic, trading costs, edge cases, and determinism
- Increase test coverage from 708 to 1,160 lines (+64%)

### Documentation
- Testing guide with verification steps (`TESTING_README.md`)
- Quick start guide with setup script (`QUICKSTART.md`)
- Test environment setup automation (`setup_test_env.sh`)
- Compatibility notes (`TEST_RUN_NOTES.md`)
